🚀 Assist Chat Widget

Willkommen zur Demo des Assist Chat Widgets! Dieses Widget kann auf jeder Webseite eingebunden werden und bietet KI-gestützten Chat-Support für Ihre Kunden.

Aktuelle Konfiguration:

Customer ID: default

Position: Unten rechts

Auto-Open: Nein

Klicken Sie auf das Chat-Icon unten rechts, um das Widget zu öffnen!

Einbindung:

So einfach binden Sie das Widget auf Ihrer Webseite ein:

<script
  src="http://localhost:3000/widget.js"
  data-customer-id="default"
  data-server-url="ws://localhost:3000/chat"
></script>
